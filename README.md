# Sewer-Linear-System-Identification
This is the Github repository of the paper "Linear System Identification of Urban Drainage Systems with the Integrator-Delay-Zero Model" by Chuanning Wei, Trent Suzuki, and Margaret Chapman

The code has three formats: PCSWMM files that has suffix .inp, python files that has suffix .py, and matlab files that has suffix .m or .mat. We construct our sewer system map in the .inp files, all the computations are done in matlab files, and the python file uses pyswmm to read PCSWMM data and interact with PCSWMM model.

That is, you need to install pyswmm from their website https://www.pyswmm.org/. You will also need to have a license in PCSWMM. Next we introduce how to run the programs.

Take Simulation II as example, running the program consists of four steps:
- Go to the PCSWMM .inp file and save the rainfall profile as rainfall.dat in the root directory.
- Run pyswmm_interface.py to read data from its specified path. This saves a matlab data file hurricane_dw.mat.
- Run controller_compute.m to obtain the LQR controller (saved as control_matrices.mat), note this file is the main component of the work.
- Run pyswmm_control.py to generate plots, which uses the matlab function plot_result.m.

(Before running the program, you should type the command matlab.engine.shareEngine in your Matlab command line.)

In Simulation I, controller_compute.m is called model_construction.m, and step 3 does not exist. The simulation plots are generated by model_construction.m.
